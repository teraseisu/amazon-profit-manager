アカウント設定
複数のAmazonセラーアカウントを管理できます
APIキーはVercelの環境変数に安全に保存されています。
アカウント名はブラウザに保存されます。新しいアカウントを追加する場合はVercelに環境変数を追加してください。
Vercel 環境変数の設定方法
1. vercel.com/dashboard → プロジェクト → Settings → Environment Variables
2. アカウント番号ごとに以下を追加（1つ目はそのまま、2つ目以降は _2, _3 をつける）：
// 1つ目のアカウント
SELLER_ID = A2LF1TDDMCBMMT
CLIENT_ID = amzn1.application-oa2-client.xxxx
CLIENT_SECRET = シークレットキー
REFRESH_TOKEN = Atzr|xxxx

// 2つ目のアカウント
SELLER_ID_2 = B3MG2UEENCLDNU
CLIENT_ID_2 = amzn1.application-oa2-client.yyyy
CLIENT_SECRET_2 = シークレットキー2
REFRESH_TOKEN_2 = Atzr|yyyy
3. 追加後 Deployments → Redeploy で反映
