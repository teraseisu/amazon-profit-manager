接続状態の確認
Vercelへの環境変数の設定方法
1. vercel.com/dashboard を開く
2. amazon-profit-manager プロジェクトをクリック
3. Settings → Environment Variables を開く
4. 以下の4つを追加する：
SELLER_ID = あなたのセラーID
CLIENT_ID = amzn1.application-oa2-client.xxxx
CLIENT_SECRET = シークレットキー
REFRESH_TOKEN = Atzr|xxxx
5. 追加後、Deployments → 最新のDeployment → Redeploy で反映

利益計算に使うデフォルト値を設定します（ブラウザに保存）
SKU 判別ルール
新品
パターン: m_m[数字]（ハイフンなし）
例: m_m93592455612
中古
パターン: m_m[数字]-[仕入れ値]（ハイフンあり → 自動取得）
例: m_m53368356227-2249 → 仕入れ値 ¥2,249
